# Diary Coder

Diary Coder — локальный PWA-дневник для шифрования и расшифровки записей в формате `DC1.<base64url>`.

## Локальный запуск

Service Worker требует HTTP/HTTPS-контекст. Из каталога проекта запустите простой локальный сервер, например:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

> Не открывайте `index.html` напрямую через `file://`, если хотите проверить установку PWA и офлайн-режим.

## HTTPS hosting

Разместите все файлы проекта без изменений на статическом HTTPS-хостинге. Корень сайта должен соответствовать `start_url: "/"` и `scope: "/"` из `manifest.webmanifest`.

Подойдут обычные static hosting-платформы или собственный HTTPS-сервер. Приложению не нужен backend.

## iPad

1. Откройте HTTPS-адрес приложения в Safari.
2. Нажмите **Share**.
3. Выберите **Add to Home Screen**.
4. Запускайте Diary Coder с домашнего экрана как отдельное приложение.

## Privacy

Пользовательский текст и пароль не сохраняются в localStorage, sessionStorage, IndexedDB или cookies и не отправляются в сеть. Service Worker кэширует только статические файлы приложения.
